# 比例计算器（报价倍率）设计文档

## 概述
为白卡盒算价系统新增报价倍率功能。当前系统计算的为**成本价**，需支持用户设置倍率后自动计算**报价**（含利润）和**利润率**。

## 设计决策
- **方案**：在现有报价结果卡片（`.price-result`）内部集成，成本价→倍率→报价在同一视觉区域
- **默认倍率**：1.30（30%毛利率）
- **预设按钮**：×1.1、×1.2、×1.3、×1.5、×2.0

## UI 布局（新增部分的 HTML 结构）
在 `.price-result` 卡片内，现有纸重/运费信息之上，新增两个区块：

### 1. 成本价展示（当前总价改为"成本价"标签）
- 原 `.price` 元素增加 `cost` 标识，标注为"成本价"

### 2. 倍率控件区
- 预设按钮行：使用现有 `.option-group` 样式，5个预设按钮
- 自定义输入行：数字输入框，步进 0.01，范围 1.00~10.00

### 3. 报价结果区
- 报价总价（大字突出显示）
- 利润率（百分比，绿色/红色根据阈值）
- 利润金额
- 报价单价

## 交互逻辑
| 操作 | 行为 |
|------|------|
| 点击预设按钮 | 设置倍率，实时计算 |
| 输入自定义倍率 | 实时计算 |
| 切换盒型/参数 | 保持当前倍率，成本变化后自动更新报价 |
| 倍率=1.00 | 报价=成本，利润率=0% |

## 计算公式
```
报价 = 成本价(total) × 倍率(multiplier)
利润 = 报价 - 成本价
利润率 = (报价 - 成本价) / 报价 × 100%
```

## 修改文件
- `index.html` — 唯一需要修改的文件
  - CSS：新增 `.price-result` 内部控件样式（复用现有变量）
  - HTML：新增倍率控件区 + 报价/利润率展示区
  - JS：`S.multiplier` 状态变量 + `calcPrice()` 末尾增加倍率计算

## 约束
- 零外部依赖（纯 HTML/CSS/JS）
- 完全遵循现有 Glassmorphism 视觉风格
- 不破坏现有任何功能
- 倍率变更不修改 `total` 成本价变量本身

## 不包含的范围
- 不添加数据库/持久化倍率设置
- 不修改运费计算逻辑
- 不改变现有盒型/材料/工艺等任何定价参数
